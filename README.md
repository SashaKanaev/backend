# Модерация объявлений

Небольшой сервис на FastAPI. `POST /predict` принимает объявление и возвращает JSON `true`, если есть нарушение, или `false`, если нарушения нет. По условию нарушение есть только у неподтверждённого продавца без изображений.

Для запуска из папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
fastapi dev
```

Документация откроется на http://127.0.0.1:8000/docs. Корневой `GET /` возвращает `{"message": "Hello World"}`.

Пример запроса:

```bash
curl -X POST http://127.0.0.1:8000/predict \
  -H 'Content-Type: application/json' \
  -d '{"seller_id":1,"is_verified_seller":false,"item_id":10,"name":"Велосипед","description":"Продам велосипед","category":2,"images_qty":0}'
```

Ответ: `true`.

Все семь полей обязательны. ID продавца, объявления и категории — положительные целые числа, количество изображений — неотрицательное целое. Название и описание не могут быть пустыми или состоять только из пробелов. Типы строгие: строка `"1"` не заменяет число, а `0` не заменяет boolean. Лишние поля запрещены.

Успешный запрос возвращает 200 и одно булево значение. Ошибки входных данных возвращают 400 с указанием полей. Неожиданные ошибки возвращают 500 без внутренних подробностей; сама ошибка записывается в лог.

Обработчик и схема запроса находятся в `main.py`, правило модерации — в `service.py`, хранение последнего результата по `item_id` — в `repository.py`. Хранилище учебное, в памяти процесса. При перезапуске данные теряются; отдельная база для этого задания не нужна.

Тесты запускаются командой `python -m pytest -q`. Они проверяют правило модерации, обязательные поля, типы и диапазоны значений, некорректный JSON, ошибки сервиса и репозитория, формат ответа и документацию API.
